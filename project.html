MFG — Mama's Fried Goods

Next.js · Sanity CMS · Stripe · Supabase · Resend

A full-stack food delivery platform built for a real London food business specialising in Nigerian cuisine and diverse comfort food. Customers browse a rotating menu, add items to cart, and pay online. The business owner manages the menu independently through Sanity CMS with no code changes required.

  • CMS-driven rotating menu — owner publishes dishes instantly, site updates in 60s
  • Stripe webhook integration saves orders to PostgreSQL after payment
  • Automated customer confirmation and owner notification emails via Resend
  • Admin order dashboard protected by secret key
  • All monetary values stored in pence to avoid floating point precision bugs
